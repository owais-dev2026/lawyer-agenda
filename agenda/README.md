# أجندة المحامي

تطبيق ويب يعمل دون إنترنت لإدارة جلسات المحاكم والموكلين.

## التشغيل محلياً

```bash
pnpm install
pnpm dev
```

افتح http://localhost:3000

## النشر على الإنترنت (للتثبيت على الجوال)

1. ارفع المجلد على GitHub
2. ادخل إلى https://vercel.com وسجّل بحساب GitHub
3. Import المشروع وانشره (مجاني)
4. ستحصل على رابط مثل: `https://lawyer-agenda.vercel.app`

## تثبيت التطبيق على الجوال

### أندرويد (Chrome)
1. افتح رابط التطبيق في Chrome
2. القائمة ⋮ → **إضافة إلى الشاشة الرئيسية** أو **تثبيت التطبيق**

### آيفون (Safari)
1. افتح الرابط في Safari
2. زر المشاركة → **إضافة إلى الشاشة الرئيسية**

البيانات تُحفظ على الجهاز فقط وتعمل دون إنترنت بعد أول فتح.
